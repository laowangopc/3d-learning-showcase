# Security

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature if it is enabled, or contact the repository owner privately. Do not publish credentials, user data, or working exploit details in an issue.

This repository contains no production secrets. Keep `.env`, `secrets/`, databases and uploaded files outside Git. The example Compose file binds only to loopback; add HTTPS, backup, monitoring and an access review before any public deployment. Resource uploads require licence and provenance review before publication.
